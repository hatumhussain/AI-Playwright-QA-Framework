# AI-Powered Playwright QA Automation Framework

A Python-based UI test automation framework built using **Playwright, Pytest, and the Page Object Model (POM)**, with local AI-powered failure analysis using **Ollama and Llama 3.2**.

## Key Features

* Web UI automation with Playwright and Pytest
* Page Object Model (POM) for maintainable test code
* Positive and negative login testing
* Homepage, products, cart, and checkout test coverage
* Automatic screenshots on test failures
* Local AI-assisted failure analysis using Ollama
* HTML test reports
* GitHub Actions CI workflow and Jenkins pipeline configuration

## Tech Stack

Python | Playwright | Pytest | Ollama | Llama 3.2 | GitHub Actions | Jenkins

## Purpose

This project demonstrates practical UI automation, test framework design, and AI-assisted debugging as an extension of my 5 years of manual QA experience.
